To add project reports or code:

1.  Place your Report PDF here and name it matching the link in `src/data/profile.ts` (e.g., `lithium-recycling-report.pdf`).
2.  Place your Code Zip here (e.g., `sizing-program-code.zip`).
3.  Place your Model PDF here (e.g., `blending-unit-design.pdf`).

If you change the filenames here, make sure to update `src/data/profile.ts` `links` section to match.
